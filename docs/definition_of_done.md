# Definition of Done

A ticket is Done when:
- [ ] Code is merged to `main` through a pull request
- [ ] Tests pass in CI
- [ ] Data transformations have schema and null checks
- [ ] Models are logged in MLflow with metrics
- [ ] Docs or model card updated where relevant
- [ ] Acceptance criteria on the ticket are met
- [ ] Ticket is linked to the PR and moved to Done

## Working agreements
- Branch names: `KEY-123-short-description`
- Commit messages start with the ticket key
- Spikes are time-boxed; findings are written in the ticket and `docs/`
- New ideas mid-sprint go to the backlog
